## v1.0.0-beta.15 — Window and Interaction Improvements

Groups the main workflow in the first action row. Adds DPI-aware viewport scaling, scrolling, keyboard controls, pointer feedback, visible disabled states, wrapped notices and quick access to the last successful save. Header positions and existing palette remain consistent.

## v1.0.0-beta.14 — UI Layout & Tether Guidance

Fixed action-card descriptions that were drawn into a 12px-high rectangle despite needing 19px. Titles and descriptions now fit inside both compact action cards and taller welcome cards.

The character and language controls have fixed header positions. The official 2D guide sticker joins the existing 3D states. Single-line labels are centered vertically, and the welcome screen and camera list clarify USB tether requirements and the difference between tether support and counter verification.

## v1.0.0-beta.13 — Language Selection & UI Polish

The header now offers Windows Auto, Korean and English. The selected language is saved per Windows user. Korean/English typography, verified-camera rows, export spacing and creator information were refined.

## v1.0.0-beta.12 — Provisional Counters & Auto Language

Unverified models now show provisional shutter and power/wake names alongside clear validation warnings. The interface and report use Korean or English according to the Windows user interface language.

## v1.0.0-beta.11 — Red / Blue & USB Guide

Deep red marks the main connection action and shutter, while blue marks USB and connected-camera information. The welcome screen explains camera power, USB cable connection and the camera's PC(Tether) selection.

## v1.0.0-beta.10 — Palette & Mascot Placement

Kept the dark canvas and unified interface accents around warm apricot and soft teal. Action-card borders are neutral; the official Lumerian character appears within the connection and camera panels. Camera behavior is unchanged.

## v1.0.0-beta.9 — Dark Dashboard Design

Kept the near-black canvas and official Lumerian character. Redesigned the connection and camera dashboards with a clear status panel, readable counter cards and color-coded action cards. Camera reading and other functions remain the same.

## v1.0.0-beta.8 — Lumerian Brand & Character

Established Lumerian as the product brand and official cream-and-golden puppy photographer guide in a red hoodie. Added a consistent four-state character system for default, information, successful export and recoverable error views, plus product wording and reusable brand guidance.
