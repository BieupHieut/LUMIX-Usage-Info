# Lumerian · LUMIX Usage Info v1.0.0-beta.18

2026-10-02 · Windows x64

## 변경 사항

- 사용자 확인에 따라 **DC-L10 / FW 1.2**, **DC-S1M2 / FW 1.4**의 셔터·전원/깨우기 의미를 VERIFIED로 반영했습니다. 검증자: **잠이든**. 카운터 3–7과 오류 코드 해석은 별도 미검증입니다. 모델별 촬영 동작의 상세 증가 규칙까지 동일하다고 일반화하지 않습니다.
- 검증 및 정보와 카메라 목록을 한 화면으로 합쳤습니다. 홈 → 검증 및 정보에서 검증된 5개 조합을 바로 봅니다. 버전 기록·개발자 정보·뒤로 버튼은 하단 한 줄에 배치했습니다.
- 영어 UI·리포트·문서의 카페 이름: **Panasonic LUMIX Café Forum**. 한국어: **파나소닉 루믹스 카페 포럼**. 확인자 닉네임은 원문을 유지합니다.
- 창 스크롤 수정: 기본 창 스타일에 스크롤바를 항상 생성하지 않습니다. 스크롤바가 없는 공간을 기준으로 가로/세로의 필요 여부를 함께 계산합니다. 화면이 충분히 들어가는 창은 두 스크롤바를 제거하고 이동만으로 불필요한 스크롤을 만들지 않습니다. 작은 창·큰 배율에서는 필요한 스크롤을 유지합니다.
- L10은 **LUMIX Lab** 선택 후 기존 일반 연결/새로고침을 사용합니다. 별도 연결 개발이나 진단 메뉴를 추가하지 않습니다.
- 홈·검증 표시·PNG·TXT·요약·제작자 화면에 정확한 펌웨어별 VERIFIED 상태와 검증자 이름을 반영했습니다. 다른 펌웨어와 S1M2ES까지 확장하지 않습니다.

## 검증 근거

잠이든 님의 L10 1.2 / LUMIX Lab / beta.6 읽기 화면과 S1M2 1.4 읽기 제보를 받았고, 프로젝트 사용자가 두 기종의 카운터 의미도 동일하다고 추가 확인했습니다. 상세 전후 로그와 실제 시험 날짜는 미제공이며 검증 날짜를 임의로 넣지 않습니다. 접수일은 2026-10-02입니다. 개발자가 beta.18을 두 실물 카메라에 직접 연결한 결과는 아닙니다.

## 검사 및 실행

소스 회귀/모의 전송/정확한 펌웨어 검증/한영 리포트/자체 GDI 배치와 배율 검사를 수행했습니다. 숨김 Win32 창에서 작은 창·확대·정확히 맞는 크기·기존 스크롤바 강제 생성 후 제거·이동만 수행·키보드·DPI 메시지를 검사했습니다. 실제 카메라와 native 저장 대화상자는 대상 PC에서 재확인하세요.

기존 프로그램을 종료하고 `LUMIX_Usage_Info_v1.0.0-beta.18.exe`를 실행합니다. 일반 기종은 PC(테더), DC-L10은 LUMIX Lab을 선택하고 연결/새로고침을 사용하세요. 소스와 ZIP은 로컬에 저장했으며 GitHub/카페 게시를 하지 않았습니다.
