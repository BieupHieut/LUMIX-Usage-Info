# Lumerian · LUMIX Usage Info v1.0.0-beta.17

2026-10-02 · Windows x64 · 비공식 읽기 전용 커뮤니티 도구

## 변경 사항

- DC-L10을 기존 일반 WPD/PTP 조회 경로로 통합했습니다. beta.16의 L10 제외 분기를 제거했습니다. 별도 L10 테스트 메뉴와 worker 진입은 정규 앱에 노출하지 않습니다.
- 연결 안내: 일반 지원 기종은 PC(테더), DC-L10은 LUMIX Lab을 선택합니다. 기존 ‘테더가 없으면 미지원’ 절대 안내를 수정했습니다.
- 잠이든 님의 DC-L10 / FW 1.2 / LUMIX Lab / beta.6 화면 사례와 DC-S1M2 / FW 1.4 읽기 성공 제보를 추가했습니다. S1M2의 툴 버전과 실제 USB 모드는 미제공입니다.
- 카메라 목록·홈 하단·검증 및 정보·TXT·복사 요약·PNG 검증 문구에 읽기 제보 상태를 적용합니다. 읽기 확인자는 카운터 의미 검증자와 구분합니다. 보고서의 연결 모드는 과거 제보값이며 현재 모드를 자동 감지한 결과가 아닙니다.
- 제작자 화면에 **Special Thanks · 도움을 주신 분들**로 파나소닉 루믹스 카페 포럼 회원 여러분을 표시합니다. 개별 확인자의 기종과 펌웨어도 함께 표시합니다.
- 검증 및 정보 화면에서 미검증 연결 기종이 다른 검증 기종으로 바뀌어 표시되던 문제를 수정했습니다. 실제 기종의 미검증 범위를 표시합니다.
- 기존 검정 배경·루메리안·한/영 전환·PNG/TXT·시리얼 공개 범위·오류/원시 카운터 기능을 유지합니다. 하단 글자 사이 간격을 확보했습니다.

## 확인 범위

읽기 성공 제보는 **셔터·전원 횟수의 의미 검증을 뜻하지 않습니다**. DC-S1RM2 / 1.5, DC-S5M2 / 3.7, DC-S5 / 2.9의 기존 VERIFIED 조합은 유지합니다. 신규 L10/S1M2의 명칭은 잠정 표시이며 Raw Counter 2 / 1의 대응과 미검증 경고를 남깁니다. 카운터 3–7의 의미와 최신 기종의 오류 코드 해석도 미검증입니다.

개발자가 실제 L10/S1M2에 연결해 beta.17을 시험한 것은 아닙니다. 읽기 제보의 근거 버전과 이번 빌드 검사는 별도입니다. L10의 일반 읽기는 표준 모델 확인과 성공 응답/태그/정확한 146바이트 payload 조건을 검사합니다. 다른 구조의 응답은 임의로 해석하지 않습니다.

## 실행

기존 앱을 종료하고 `LUMIX_Usage_Info_v1.0.0-beta.17.exe`를 실행하세요. 카메라를 데이터 USB 케이블로 PC에 연결하고 일반 기종은 PC(테더), L10은 LUMIX Lab을 선택하세요. 연결/새로고침 후 리포트를 저장할 수 있습니다. 다른 카메라 앱이 점유하고 있다면 종료하세요.
