# DC-L10 / DC-S1M2 읽기 성공 제보

기록일: 2026-10-02 · 자료 제공: 프로젝트 사용자

읽기 확인자: **잠이든** 님 (DC-L10 / FW 1.2, DC-S1M2 / FW 1.4).

커뮤니티: [파나소닉 루믹스 카페 포럼](https://cafe.naver.com/panalumix). 사용자는 잠이든 님과 기존 확인자분들이 모두 해당 포럼 회원이라고 설명했습니다. 회원 여부는 사용자 제공 출처이며 별도로 조회하지 않았습니다. 기존 기종별 확인자 이름과 검증 범위는 유지합니다.

L10 화면은 `Unverified model`이며 원시 카운터 의미를 적용하지 않는다고 표시합니다. 오류 영역에는 16개 슬롯에서 0이 아닌 오류가 발견되지 않았다는 결과가 있습니다. 이것만으로 L10 오류 코드 해석이 검증되지는 않습니다. 시리얼은 기록하지 않았습니다.

## 해석

DC-L10은 기존 일반 프로그램에서 모델·펌웨어·원시 값이 표시된 읽기 성공 사례를 확보했습니다. 사용자가 LUMIX Lab 모드로 연결했다고 확인했습니다. 기존 읽기 경로가 해당 모드에서도 동작한 사례로 기록합니다. 전체 응답 길이·태그·7개 값·반복 측정 로그는 아직 확보하지 못했습니다.

일반 프로그램의 기존 매핑은 Counter 2를 셔터 후보, Counter 1을 전원/깨우기 후보로 사용합니다. 이 화면의 1,387과 404는 각각 그 후보 값이며, L10에서도 실제 셔터/전원 횟수라는 뜻으로 확정하지 않습니다. 리프 셔터의 물리 동작과 내부 카운터 증가 규칙을 따로 시험해야 합니다.

DC-S1M2는 사용자 확인 펌웨어 V1.4의 읽기 성공 제보가 있고 기존 테더 대상 목록에도 있습니다. 사용자는 현재 최신 펌웨어라고 설명했습니다. 리포트·툴 버전·실제 선택 USB 모드·촬영 전후 변화량은 미제공입니다. 카운터 의미의 VERIFIED 목록에는 추가하지 않습니다. DC-S1M2ES까지 확장하지 않습니다.

2026-10-02에 확인한 [Panasonic 공식 다운로드 페이지](https://av.jpn.support.panasonic.com/support/global/cs/dsc/download/ff/dl/s1m2.html)도 DC-S1M2의 최신 다운로드를 Ver.1.4 (2026-03-10)로 표시합니다. 공식 페이지는 펌웨어 버전의 근거이며 이 비공식 프로그램의 읽기 성공이나 카운터 의미를 검증하는 근거는 아닙니다.

## 현재 버전과의 차이

beta.16 일반 조회에는 DC-L10을 수동 USB 테스트로 안내하는 명시적 분기가 있습니다. 이는 beta.6의 실제 읽기 성공과 별개인 프로그램 제한입니다. beta.6의 화면을 근거로 beta.16 일반 조회도 그대로 성공한다고 안내하지 않습니다.

L10 USB Test v0.1.0은 비교와 자세한 진단을 위한 독립 시험 도구로 사용할 수 있습니다. beta.6에서 이미 읽기가 되는 사례에 별도 프로그램 실행이 필수라는 설명은 하지 않습니다.

## 권장 후속 개선

1. 다음 정규 버전에서 L10의 일반 읽기를 통합할 방안을 검토하고 beta.16의 L10 전용 제한을 함께 수정합니다. 읽기 성공과 카운터 의미 검증을 별도 상태로 표시합니다.
2. “테더 기능이 없는 카메라는 지원되지 않습니다”라는 절대 안내를 수정합니다. 제안 문구: **카메라를 켜고 데이터 USB 케이블로 PC에 연결하세요. 일반 지원 기종은 PC(테더), DC-L10은 LUMIX Lab을 선택해 주세요.** L10은 beta.6 / FW 1.2 / LUMIX Lab 연결에서 읽기 성공 사례가 있으며 다른 버전과 기종으로 일반화하지 않습니다.
3. 잠이든 님이 확인한 L10 / FW 1.2 / LUMIX Lab을 ‘화면 근거 및 연결 모드 제보가 있는 읽기 성공 사례’로, S1M2 / FW 1.4를 ‘읽기 성공 제보’로 기록합니다. VERIFIED 기종/펌웨어 3쌍은 유지합니다. 확인자와 커뮤니티 출처를 이후 정규 버전의 결과/크레딧에 반영합니다.
4. L10 기본 리포트와 S1M2 리포트·툴 버전·USB 모드를 확보합니다. 원시 값 7개, 응답 구조, 반복 읽기의 변화를 확인합니다.
5. L10에서 아무 동작 없이 2회 읽는 대조 시험부터 진행한 뒤, 명시적 기계식 10장·전자식 10장·전원 끔/켬 1회·절전/깨우기 1회를 각각 분리해 비교합니다. 기계식/전자식+NR 동작을 구분하고 재연결·전원 변화가 섞이면 메모합니다.
