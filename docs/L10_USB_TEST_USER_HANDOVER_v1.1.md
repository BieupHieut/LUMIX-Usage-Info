# LUMIX Usage Info — L10 전용 USB 연결 테스트 개발 작업지시서 / HANDOVER

- 문서 버전: **1.1 (L10 전용으로 범위 변경)**
- 기준일: 2026-10-02
- 기준 제품: **LUMIX Usage Info v1.0.0-beta.12 / Windows x64**
- 신규 실험 대상: **DC-L10 / 펌웨어 1.2 우선** (다른 펌웨어는 실제 버전 기록 후 별도 취급)
- 상태: **구현 작업지시서 / L10의 Windows LUMIX Lab USB 통신 미확인 / 실기기 검증 대기**
- 최상위 원칙: **기존 기능 무변경 · L10 전용 수동 테스트 버튼 · 읽기 전용 · 수집 최소화 · 테스터의 단계별 동의**

> **핵심 변경:** 기존 v1.0 문서에 있던 S9의 Tether/Lab 비교 실험과 범용 USB 진단 탭을 **이번 작업에서 전부 제외**한다. **S9은 기존 PC(Tether) 연결 경로로 두고**, L10만 별도 버튼을 통해 시험한다. 단, S9에 테더 기능이 있다는 사실이 현재 Usage Info 버전에서 S9의 셔터 카운터 의미까지 검증됐음을 뜻하지는 않는다.

## 0. 개발 목적 및 범위

L10 실기기를 보유하지 않은 개발자가 L10 보유자에게 테스트 빌드를 배포하여, 카메라에서 **LUMIX Lab USB 모드**를 선택했을 때 Windows에서 발견되는 장치 정보와 기존 WPD/PTP 읽기 기능의 재사용 가능성을 검증한다. 결과는 **사용자가 직접 검토하여 내보내고 자발적으로 제출**할 수 있어야 한다. 

### 포함

1. 기존 `VALIDATION & INFO` 안에 **`L10 USB 연결 테스트 (Beta)` 버튼 하나** 추가. 메인 화면에 별도 범용 진단 탭은 만들지 않는다.
2. 버튼 클릭 시 **L10 전용 독립 모달 또는 독립 진단 화면** 열기. 첫 화면에 카메라 USB 설정 `LUMIX Lab` 선택 안내.
3. **A: USB 장치 인식** → **B: 표준 PTP 정보 조회(조건부)** → **C: 기존 Panasonic 읽기 조회(별도 동의·조건부)** 순서의 단계별 수동 테스트.
4. **진단 요약/개인정보 보호/JSON+TXT 수동 내보내기** 및 다른 사용자에게 전달할 짧은 사용 안내.
5. 카메라가 없어도 작동하는 **익명 가상 데이터 기반 UI/보고서 테스트**.

### 제외

- **S9 전용 테스트 버튼, S9 Lab 실험, S9 대조 실험 및 USB 모드 선택 목록.** S9용 특별한 탐지·전송 분기는 추가하지 않는다.
- LUMIX Lab 전체 기능 복제, 스마트폰 앱 모사, 블루투스 인증/페어링 재현, 촬영 원격제어.
- 펌웨어 패치·플래시, USB 드라이버 강제 교체, ROM/EEPROM 쓰기, 서비스 모드 변경, 미확인 명령 무작위 탐색.
- 테스트 성공 전 **'L10 지원', 'L10 셔터 횟수 조회 성공', 'Lab 프로토콜 호환'** 문구 표시.

## 1. 확인된 기술 기준 및 미확인 사항

### 기존 프로젝트에서 확인된 사실

- 기존 Usage Info beta.12는 Windows x64의 비공식 **읽기 전용** 도구다. 검증 명시 조합은 S1RII 1.5, S5II 3.7, S5 2.9이며, 기존 검증 표기를 회귀시키지 않는다.
- 기존 인계문서(beta.6)에 기록된 전송/명령은 **Windows WPD/PTP**, 표준 **`0x1001` GetDeviceInfo**, Panasonic **`0x9414` + `0x15C00010`**, 예상 SetupInfo TLV **`0x15C00011`**이다.
- **S1RII 1.5에서** 확인한 응답은 146바이트: 앞 128바이트는 16×8바이트 오류 이력, 뒤 18바이트는 `u32, u32, u16, u16, u16, u16, u16`. Counter #1 = 전원/깨우기, Counter #2 = 셔터 작동, #3~#7 미확인. **이 해석을 L10에 자동 적용 금지.**
- 기존 카메라 읽기는 **시간 제한이 적용된 별도 워커 프로세스**에서 실행된다. 메인 UI 블로킹을 유발하지 않는다.

### 제조사 설명에서 확인한 사실과 추론의 경계

- **DC-L10은 USB `LUMIX Lab` 모드를 제공하며 `PC(Tether)` 기능은 제공하지 않는다.**
- 하지만 **L10의 Lab 모드에서 Windows에 노출되는 USB 인터페이스, PTP 지원 여부, 별도 연결 등록 필요 여부, 기존 `0x9414` 명령 수용 여부는 확인되지 않았다.**
- 펌웨어 업데이트 파일의 `history` 영역은 **각 실기기의 실시간 누적 셔터 횟수가 저장된 파일이라고 간주할 수 없다.** 장치의 실제 사용 이력을 얻으려면 카메라와의 통신이 필요하다.

## 2. 사용자가 실제로 보는 UI 명세

### 기존 화면 (변경 최소화)

```text
LUMIX Usage Info
├─ [기존 카메라 연결 / 새로고침 / 결과 / PNG·TXT 기능]   ← 모두 보존
└─ VALIDATION & INFO
   ├─ [기존 검증 기종 목록 / 버전 기록 / 개발 정보]       ← 모두 보존
   └─ [L10 USB 연결 테스트 (Beta)]                     ← 새 버튼 1개
```

- 버튼은 **수동 진단 시작 전용**이다. 버튼의 존재가 메인 화면의 카메라 자동 인식/기존 정상 동작에 영향을 주면 안 된다.
- 메인 화면에서 L10에 기존 테더 연결을 요구하는 팝업을 자동으로 띄우지 않는다.
- 버튼을 누르지 않은 경우 L10용 새 스캔, PTP 명령 또는 원본 수집은 **실행하지 않는다**.
- 버튼 클릭 시 모달 또는 독립 창에서 다음 상태를 표시한다.

### 전용 진단 화면의 화면 문구 예시

```text
L10 USB 연결 테스트                               [BETA]

대상: DC-L10 (전용 실험 기능 · 아직 호환성 미검증)
카메라에서 USB 모드를 'LUMIX Lab'으로 선택하세요.
데이터 전송이 가능한 케이블로 Windows PC에 연결하세요.
이 기능은 LUMIX Lab 정식 앱이 아니며, 읽기 전용 USB 통신을 시험합니다.

카메라 펌웨어: [1.2     ] (직접 확인/입력)
[1. USB 장치 확인]

USB 후보를 찾은 뒤 사용자에게 대상 장치 선택 요청
장치명: ...   VID: ...   PID: ...   인터페이스: ...
[2. 표준 PTP 확인]   ← 1번에서 PTP 접근 가능성이 확인될 때만 활성화
[3. 기존 읽기 조회]  ← 2번 성공 + 적합성 검토 + 별도 동의 후에만 활성화

단계별 상태: NOT RUN / PASS / UNSUPPORTED / INACCESSIBLE / TIMEOUT / ERROR
[개인정보 제거 보고서 미리보기] [JSON + TXT 저장] [닫기]
```

- L10이 발견되지 않아도 장치 검색의 음성 결과(`DEVICE_NOT_FOUND`)를 보고서로 저장할 수 있어야 한다.
- 연결 모드 `LUMIX Lab`은 **사용자 입력/선택**이다. USB 장치 열거 결과만으로 실제 모드를 확인했다고 표시하지 않는다.
- **USB 발견됨 ≠ LUMIX Lab 통신 성공 ≠ 셔터 횟수 검증됨**을 UI에 명확히 표시한다.
- **S9은 이 화면의 기종 옵션으로 나타나지 않는다.** L10 이외 기종이 선택된 경우 진단을 진행하지 않고 기존 연결 방법을 안내한다.

## 3. 진단 처리 절차 및 안전 게이트

### A. USB 장치 확인 (첫 번째 버튼, 명령 전송 없음)

1. 연결 전후 Windows USB/PnP 장치 목록을 비교하고, Panasonic 후보와 사용자가 지정한 장치만 보여 준다. 단, VID만으로 모델을 확정하지 않는다.
2. 가능하면 VID/PID, 표시명, 구성·인터페이스 번호, USB 클래스/서브클래스/프로토콜, 엔드포인트 방향과 전송 형식, 드라이버 이름을 **OS에서 정상 제공하는 범위에서만** 기록한다.
3. Windows가 비워 둔 필드는 `not available`로 남긴다. 정보를 얻으려고 기존 드라이버를 교체하거나 장치를 강제로 점유하지 않는다.
4. 다른 Panasonic USB 기기가 함께 연결돼 있으면 사용자에게 정확한 장치 선택을 요구한다. 다른 모델을 L10으로 자동 확정하지 않는다.
5. USB가 안 보이는 경우 케이블·전원·LUMIX Lab 모드 재확인을 안내한다. 자동 재시도나 강제 연결은 하지 않는다.

**A 성공 기준:** 사용자 지정 후보 장치의 비식별 USB 기초 정보가 확보됨. Windows USB 장치로 열거됐다는 사실 이상의 호환성 주장은 하지 않는다.

### B. 표준 PTP 확인 (두 번째 버튼, 조건부)

1. A에서 선택한 장치에 PTP 인터페이스 또는 기존 WPD/PTP로 열 수 있는 경로가 확인된 경우에만 버튼 활성화.
2. 사용자에게 **표준 카메라 정보 1회 조회** 범위와 실패 가능성을 설명하고 명시적으로 동의를 받는다.
3. 이미 존재하는 WPD/PTP 전송 계층을 통해 **`0x1001` GetDeviceInfo만** 호출한다. 제한시간·중단·연결 해제 처리 적용.
4. 결과에서 표준 프로토콜 정보 및 **지원 명령 목록**만 비식별 형태로 기록. 실제 OS 접근 거부, PTP 미노출, 장치 점유, 시간초과를 서로 다른 상태로 구분한다.
5. 실패 시 `PTP_NOT_EXPOSED`, `ACCESS_DENIED`, `DEVICE_BUSY`, `TIMEOUT` 중 확인된 이유를 표기하되 'Lab 미지원' 또는 '카운터 없음'으로 추정하지 않는다.

**B 성공 기준:** PTP `GetDeviceInfo`가 실제 응답함. 이것만으로 Lab 연결 초기화 성공이라고 하지 않는다.

### C. 기존 Panasonic 읽기 조회 (세 번째 버튼, 별도 동의·엄격 게이트)

- **C를 테스트 빌드에서 무조건 활성화하지 말 것.** B 성공 후 해당 장치의 지원 명령 목록에 `0x9414`가 표시되거나 그와 동등한 적합성 근거를 개발자가 검토해 승인한 경우에만 활성화한다.
- 별도 팝업에서 이 기종은 아직 미검증임을 고지하고 사용자가 동의한 경우에만 기존 **`0x9414` + `0x15C00010` 1회** 시도. 알 수 없는 opcode 탐색 금지.
- TLV 태그 `0x15C00011` 존재, 정상 반환 상태 및 길이 검증. 146바이트가 아닐 경우 기존 SetupInfo 파서 적용 금지.
- 146바이트가 반환돼도 L10에서는 **원시 카운터 번호 및 변화량만 `UNVERIFIED`**로 표시. Counter #2를 '셔터 횟수'로 자동 라벨링 금지.
- 오류 이력과 원본 응답에는 민감한 장치 정보가 포함될 수 있으므로 기본 리포트에서 원문 제외. 원본 보관은 별도 목적/별도 동의가 있는 개발자 진단 경로로 한정한다.
- 자동 반복, 실패 시 우회 명령 전송, 서비스 모드 전환을 수행하지 않는다.

**C 성공 기준:** 기존 읽기 명령에 실제 정상 응답이 있으며, 상태·태그·길이 요약을 확보함. **셔터 횟수 의미 검증은 별도 작업**이다.

## 4. 모듈·안정성 구현 요구사항

- `ui/validation`: 기존 화면에 전용 **L10 버튼 하나**만 추가.
- `ui/l10_usb_test`: 세 단계 버튼·동의·상태·보고서 미리보기. S9 선택 옵션은 만들지 않는다.
- `usbdiag/enumerate`: Windows USB/PnP 후보 탐색, 모델 오인 방지, 연결 전후 비교.
- `transport/wpdptp`: 기존 검증된 WPD/PTP 계층을 **수정 없이 재사용**.
- `usbdiag/ptp_probe`: 표준 `GetDeviceInfo`를 조건부 호출.
- `usbdiag/panasonic_read_probe`: 안전 게이트 충족 시 기존 검증 명령만 호출.
- `parser/setupinfo_legacy`: 응답 길이·태그 확인 후 기존 파서. L10에서는 카운터 의미를 항상 미검증 상태로 유지.
- `report/l10_usb_test`: 마스킹 후 JSON/TXT 저장. 기존 PNG/TXT 리포트 코드 및 기본 내보내기 동작과 분리.
- `fixtures/l10`: 하드웨어 없이 열거 성공/실패·PTP 성공/실패·길이 불일치·중단을 재현하는 **가상, 비식별 테스트 데이터**.

**안정성:** 모든 실제 카메라 접근은 기존처럼 별도 워커 프로세스·제한시간·취소 경로 사용. 메인 UI가 멈추거나 다른 카메라의 연결·읽기를 방해하지 않게 한다. 단일 인스턴스 동작 및 장치 분리 대응을 유지한다.

## 5. 외부 테스터용 마스킹 보고서

- **JSON + TXT 한 번에 수동 저장**. 자동 업로드나 백그라운드 전송 금지.
- 내보내기 전 미리보기 제공. USB 장치 ID의 고유 부분·실제 시리얼·Windows 전체 장치 경로·사용자 이름·전화기/PC 식별자·페어링 키·원본 오류 이력·전체 RAW 응답 제외.
- **VID/PID와 USB 인터페이스 형식은 디바이스 유형 판별 목적상 유지**할 수 있지만, 시리얼·고유 경로는 반드시 제거한다.
- 동의 없이 전체 USB 패킷 캡처 금지. 고급 원본 수집이 나중에 필요하다면 별도 계획/동의 화면을 만든다.
- 실제 실패 사례도 유용하므로 `NOT RUN`과 `UNSUPPORTED`를 혼동하지 않고 저장한다.

```json
}
```

## 6. L10 보유자에게 전달할 앱 내 안내문

> **DC-L10 USB 연결 테스트 (Beta)**  
> L10의 USB 통신 방식과 사용 기록 읽기 가능성을 확인하기 위한 비공식 읽기 전용 테스트입니다. 카메라를 Windows PC에 USB 데이터 케이블로 연결하고, 카메라에서 **LUMIX Lab** 모드를 선택해 주세요. 먼저 **[1. USB 장치 확인]**을 누르세요. 다음 테스트 버튼은 지원 가능성이 확인된 경우에만 활성화되며, 각 단계는 별도 동의 후 실행됩니다. **셔터 횟수 표시가 아직 보장되지 않습니다.** 테스트가 끝나면 개인정보 제거 보고서를 미리 확인하고 **[JSON + TXT 저장]**을 눌러 개발자에게 전달해 주세요. 앱은 펌웨어 변경, 내부 데이터 쓰기, USB 드라이버 변경을 수행하지 않습니다.

### 제출을 요청할 정보

1. 앱이 만든 **L10 진단 보고서(JSON + TXT)**.
2. 카메라 본체에서 직접 확인한 펌웨어 버전.
3. A/B/C 단계 결과 및 오류가 난 경우 재현 방법.
4. C까지 성공한 경우에만 **별도 후속 안내**에 따라 촬영 전후 Raw Counter 변화량 확인. 카운터의 의미가 실제로 검증되기 전에는 '셔터 횟수' 인증 이미지 생성 불가.

테스터가 스마트폰 LUMIX Lab의 유선 연결에 성공했더라도, Windows 연결과 동일하다고 간주하지 않는다. 카메라가 Windows에 아예 열거되지 않는 결과도 보고서를 통해 받는다.

## 7. 구현 일정 대신 마일스톤과 완료 조건

### M1 — L10 전용 버튼 및 USB 식별 (첫 커뮤니티 테스트 배포)

- [ ] `VALIDATION & INFO`에 L10 전용 베타 버튼 하나만 추가.
- [ ] 눌렀을 때만 새 진단 경로 시작. 기존 카메라 화면 자동 인식 동작은 그대로.
- [ ] L10 Lab 모드 연결 안내, 펌웨어 직접 입력 및 장치 후보 선택.
- [ ] Windows USB/PnP의 기초 정보 취득 및 개인정보 보호.
- [ ] 미연결/충전 케이블/복수 기기/기기 점유 시에도 화면 정지 없음.
- [ ] JSON/TXT 수동 내보내기·미리보기·민감정보 제거.
- [ ] 실기기 없이 가상 샘플로 UI/보고서 단위 테스트.
- **배포 조건:** 실제 카메라에 명령을 전송하지 않고도 L10 보유자가 USB 인식 결과를 제출할 수 있음.

### M2 — 표준 PTP 읽기 (지원 가능성이 확인되면 배포)

- [ ] USB/Windows에서 PTP 접근 경로가 확인된 경우에만 B 버튼 활성화.
- [ ] 별도 동의하에 표준 `0x1001`만 조회.
- [ ] 실패 이유 세분화 및 독립 워커 제한시간/취소/재연결 시험.
- **배포 조건:** PTP가 보이지 않는 장치로 임의 명령을 보내지 않음.

### M3 — 기존 Panasonic 조회 (PTP 결과 검토 후 배포)

- [ ] 명령 지원 또는 동등한 적합성 근거 확인 전 C 버튼 잠금.
- [ ] 별도 동의 후 기존 읽기 명령 1회만 실행.
- [ ] 예상 태그/길이/상태 엄격 검증, 의미 검증 전 Raw Counter로만 표시.
- [ ] 촬영 전후 검증은 별도 승인된 후속 테스트로 분리.
- **배포 조건:** 기존 검증 기종 회귀 통과 및 L10이 미검증 카운터를 셔터 횟수로 오표시하는 경우 0건.

### M4 — 필요 시 Lab 전용 프로토콜 연구 (이번 개발 범위 아님)

PTP 경로가 없거나 읽기 명령이 제공되지 않는다면 **'L10 USB 상태 보고서'를 먼저 수집**하고 새로운 프로토콜 연구는 별도 지시서로 관리한다. 현재 단계에서 Lab 앱 전체를 재현하거나 미확인 명령을 추측해 보내지 않는다.
