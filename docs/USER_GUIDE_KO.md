# 사용자 가이드

## 다운로드와 연결

**Windows x64**에서 사용합니다. 별도 설치는 필요 없으며 이미지와 현재 검증 데이터가 EXE 안에 포함돼 있습니다.

1. [릴리즈 페이지](https://github.com/BieupHieut/LUMIX-Usage-Info/releases/latest)에서 EXE를 내려받습니다.
2. 컴퓨터의 다른 카메라 앱을 종료하고 카메라 전원을 켭니다.
3. 데이터 전송이 가능한 USB 케이블로 카메라와 컴퓨터를 연결합니다.
4. 카메라에서 **PC(테더)**를 선택합니다. **DC-L10**은 **LUMIX Lab**을 선택합니다.
5. 프로그램을 실행하고 **카메라 연결 / 새로고침**을 누릅니다.

프로그램은 카메라의 설정과 데이터를 변경하지 않습니다.
일반 지원 기종은 PC(테더) 연결이 필요하며, DC-L10은 LUMIX Lab 연결이 확인됐습니다.
`camera_profiles.json`은 [검증 데이터를 별도로 업데이트](CAMERA_DATA.md)할 때만 사용하는 선택 파일입니다.

## 표시된 값 이해하기

| 항목 | 표시 의미 |
|---|---|
| Counter 1 | 전원 / 깨우기 횟수 |
| Counter 2 | 셔터 작동 횟수 |
| Counter 3 | 플래시 작동 횟수 — 추정됨 |
| Counter 4 | 절전 작동 횟수 — 추정됨 |
| Counter 5–7 | 의미 미확인 |

Counter 1/2도 [검증된 모델·펌웨어 조합](CAMERA_SUPPORT.md) 외에는 추정됨으로 표시합니다.
추정됨은 숫자를 추측했다는 뜻이 아니라 **카운터의 의미가 아직 확인되지 않았다**는 뜻입니다.

셔터 작동 횟수는 사진 개수와 다를 수 있습니다. 일부 설정에서는 전원을 끌 때 셔터가 닫히면서 횟수가 증가할 수 있습니다.
이 값으로 남은 셔터 수명이나 고장 시점을 예측할 수는 없습니다.
오류 설명은 기존 서비스 코드 자료를 참고한 것이며, 오류 기록이 없다고 카메라 전체의 정상 상태가 보증되지는 않습니다.

## 저장과 공유

- **PNG 저장**: 용도와 시리얼 공개 범위를 고른 뒤 저장 위치를 선택합니다. **공개 공유**는 시리얼을 숨깁니다.
- **리포트 저장**: TXT로 저장하며 시리얼은 뒤 4자리만 표시합니다.
- **요약 복사**: 선택한 시리얼 공개 범위를 적용해 클립보드에 복사합니다.
- 저장 후 **최근 저장 파일 / 저장 폴더 열기**로 결과를 확인할 수 있습니다.

기본 저장 폴더: `%LOCALAPPDATA%\Lumerian\LUMIX Usage Info\Reports`

## 언어와 조작

처음에는 Windows 표시 언어를 따릅니다. 한국어 Windows는 한국어, 그 외에는 영어입니다.
상단 메뉴에서 **English / 한국어 / Windows 자동**을 선택할 수 있으며 설정이 저장됩니다.

Tab / Shift+Tab으로 버튼 이동, Enter / Space로 실행, Esc로 메뉴 닫기 또는 뒤로 이동합니다.
연결이 끊기면 마지막으로 읽은 값임을 표시합니다. 다시 연결한 뒤 새로고침하세요.

## 문제가 생겼을 때

- **카메라를 찾지 못할 때**: 데이터 USB 케이블과 카메라 USB 모드를 확인하고 다른 카메라 앱을 종료하세요. 다시 연결한 뒤 **카메라 연결 / 새로고침**을 누릅니다.
- **저장이 차단될 때**: 보호된 폴더 액세스가 선택한 폴더의 저장을 막으면 위의 기본 저장 폴더에 저장해 보세요.
- **기종 데이터 경고가 뜰 때**: EXE 옆에 별도 JSON을 놓았다면 이 저장소의 파일로 교체하거나, 파일을 제거해 내장 목록을 사용하세요. 프로그램을 다시 실행합니다.
