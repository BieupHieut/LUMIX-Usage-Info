# 사용자 가이드

## 다운로드와 연결

1. [릴리즈 페이지](https://github.com/BieupHieut/LUMIX-Usage-Info/releases/latest)에서 EXE를 받아 실행합니다. 별도 설치는 필요 없습니다.
2. 다른 카메라 앱을 종료하고 카메라 전원을 켭니다.
3. 데이터 USB 케이블로 컴퓨터와 연결합니다.
4. 카메라에서 **PC(테더)**를 선택합니다. **DC-L10은 LUMIX Lab**을 선택합니다.
5. 프로그램에서 **카메라 연결 / 새로고침**을 누릅니다.

일반 기종은 PC(테더) 연결이 필요합니다. DC-L10은 LUMIX Lab 연결이 확인됐습니다.
카메라의 설정과 데이터는 변경하지 않습니다.

## 표시된 값 이해하기

| 항목 | 의미 |
|---|---|
| Counter 1 | 전원 / 깨우기 횟수 |
| Counter 2 | 셔터 작동 횟수 |
| Counter 3 | 플래시 작동 횟수 — 추정됨 |
| Counter 4 | 절전 작동 횟수 — 추정됨 |
| Counter 5–7 | 의미 미확인 |

Counter 1/2도 [검증된 모델·펌웨어](CAMERA_SUPPORT.md) 외에는 ‘추정됨’으로 표시합니다.
‘추정됨’은 읽은 숫자가 아니라 **카운터 의미가 아직 확인되지 않았다**는 뜻입니다.

셔터 작동 횟수는 사진 수와 다를 수 있습니다. 일부 설정에서는 전원을 끌 때 셔터가 닫히면서 횟수가 증가할 수 있습니다.
이 값으로 남은 셔터 수명이나 고장 날짜를 예측할 수는 없습니다.
오류 설명은 기존 서비스 코드 자료를 참고한 것이며, 오류 기록이 없다고 카메라 전체의 정상 상태가 보증되지는 않습니다.

## 저장과 공유

- **PNG 저장**: 용도와 시리얼 공개 범위를 고른 뒤 저장 위치를 선택합니다. 공개 공유는 시리얼을 숨깁니다.
- **리포트 저장**: TXT로 저장합니다. 시리얼은 뒤 4자리만 표시합니다.
- **요약 복사**: 선택한 공개 범위를 적용해 클립보드에 복사합니다.
- 저장 후 **파일 열기 / 폴더 열기**로 결과를 확인할 수 있습니다.

기본 저장 폴더: `%LOCALAPPDATA%\Lumerian\LUMIX Usage Info\Reports`

## 언어와 조작

처음에는 Windows 표시 언어를 따릅니다. 한국어 Windows는 한국어, 그 외에는 영어입니다.
상단 메뉴에서 **한국어 / English / Windows 자동**을 선택할 수 있으며 설정이 저장됩니다.

Tab / Shift+Tab으로 버튼 이동, Enter / Space로 실행, Esc로 메뉴 닫기 또는 뒤로 이동합니다.
연결이 끊기면 마지막으로 읽은 값임을 표시합니다. 다시 연결한 뒤 새로고침하세요.

## 연결·저장이 안 될 때

- 데이터 전송이 가능한 케이블인지, USB 모드가 맞는지 확인하고 다른 카메라 앱을 종료하세요.
- 보호된 폴더 액세스 알림이 뜨면 우선 기본 저장 폴더에 저장해 보세요. 프로그램은 Windows 보안 설정을 변경하지 않습니다.
- 해결되지 않으면 [GitHub Issues](https://github.com/BieupHieut/LUMIX-Usage-Info/issues)에 모델·펌웨어·프로그램 버전과 증상을 남겨 주세요. 시리얼 전체를 공개할 필요는 없습니다.

## 기종 데이터 업데이트

현재 데이터는 EXE 안에 포함돼 있습니다. `camera_profiles.json`은 필수가 아닙니다.
추가 검증 데이터만 적용하려면 공식 저장소에서 받은 JSON을 EXE 옆에 놓고 다시 실행하세요.
[자세한 안내](CAMERA_DATA.md)
