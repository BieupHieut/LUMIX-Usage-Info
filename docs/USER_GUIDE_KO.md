# LUMERIAN LUMIX Usage Board — v1.1.1

Windows x64 · 빌드 · 2026-10-12. EXE 하나를 받아 실행하면 됩니다. 별도 설치는 필요 없고 이미지와 기종 검증 데이터가 내장되어 있습니다. 선택 파일 camera_profiles.json은 검증 목록을 별도로 갱신할 때 사용합니다.

### 화면 이동

연결 전후 모두 **카메라 / 사용 이력 / 연결 및 진단 / 기종 검증** 네 탭이 언어 선택 위 하단의 같은 위치에 있습니다.

- 카메라: 연결과 횟수 확인. 리포트 저장·기술 세부 정보·카메라 오류 기록.
- 사용 이력: 기록·바디 선택·기록 정리·저장 설정.
- 연결 및 진단: 재조회·조회 원본·진단 ZIP.
- 기종 검증: 검증된 조합과 지원 추정 목록.

앱 정보는 우측 하단에 있습니다. 버전 기록은 제품명 옆 버전을 눌러 엽니다. **좌측 원형 화살표는 해당 화면에 들어오기 직전 화면으로 돌아갑니다.** Escape 또는 Alt+왼쪽 화살표로도 이동할 수 있습니다. 여러 하위 화면을 연 경우에도 한 단계씩 돌아갑니다. 하단 탭을 선택하면 새 이동 경로가 시작됩니다. 기종 검증의 중복 앱 정보·뒤로 버튼은 제거했습니다.

### 연결과 조회

1. LUMIX Tether, 다른 카메라 앱과 이전 버전의 이 프로그램을 종료합니다.
2. 카메라 전원을 켜고 USB로 연결한 뒤 **PC(테더)**를 선택합니다. DC-L10은 **LUMIX Lab**을 선택합니다.
3. 루메리안 대문에서 **카메라 연결하기**를 누릅니다.

카메라 설정과 저장 데이터를 변경하지 않고 정보를 읽으며, 조회마다 장치 연결을 해제합니다. 지원·지원 추정 기종은 기종 검증 목록에서 확인하세요. DC-S1 / 펌웨어 2.4 카운터 지원은 보류 상태입니다.

### 세 가지 정보 카드

- **내 카메라:** 모델·펌웨어와 시리얼 표시 전환.
- **셔터 작동 횟수:** 누적 셔터 카운터.
- **전원/깨우기 횟수:** 누적 전원·깨우기 카운터이며 배터리 정보가 아닙니다.

미검증 의미에는 추정됨 / 미검증 표시를 유지하고, 조회하지 못한 횟수는 대시로 표시합니다. 카운터로 셔터의 남은 수명을 예측할 수는 없습니다. **다시 조회**로 갱신하세요.

시리얼 상자를 클릭하면 **전체 숨김 → 뒤 4자리 → 전체 보기**로 전환되며 새 조회마다 다시 숨겨집니다. 내보내기 공개 범위는 별도로 선택합니다.

### 이력과 공유

사용 횟수 조회에 성공하면 시각과 함께 로컬에 저장합니다. **사용 이력**은 카메라 연결 없이도 열 수 있습니다. 바디를 선택해 기록과 변화를 확인하며 같은 모델의 여러 바디도 구분합니다. 전체 시리얼 대신 뒤 네 자리와 로컬 식별자를 보관합니다. 시리얼을 신뢰하기 어려우면 자동 저장하지 않습니다.

**사용 이력 → 저장 설정**에서 전체 이력을 JSON으로 내보내거나 지정 사본을 갱신합니다. 자동 갱신은 이력 저장 성공 후 실행됩니다. 외부에서 파일을 변경하면 저장 위치를 다시 선택할 때까지 자동 덮어쓰기를 멈춥니다. 내부 이력은 로컬 AppData에 보관합니다. 화면 날짜는 `YYYY-MM-DD HH:MM:SS`, 파일명은 `YYYYMMDD_HHMMSS`를 사용합니다.

**리포트 저장**의 PNG·TXT·요약 복사는 모두 선택한 시리얼 공개 범위를 따릅니다. 이 화면을 열 때마다 전체 시리얼 숨김으로 시작하며, 필요하면 뒤 4자리 또는 전체 보기를 다시 선택합니다. PNG는 저장 위치를 선택하고, TXT는 로컬 리포트 폴더에 저장하며 이후 파일 열기·폴더 열기를 사용할 수 있습니다.

**중복 기록 정리**는 선택한 바디(또는 모든 카메라)에서 같은 현지 날짜의 앞뒤 기록과 셔터·전원 횟수가 모두 같은 중간 기록을 정리합니다. 최초·최신 기록, 날짜별 양 끝과 횟수 변경 전후, 펌웨어·검증 상태·카운터 초기화 경계를 보존합니다. 삭제 건수를 확인한 뒤 진행하세요. `history-backups`에 전체 로컬 백업을 먼저 만들며 **이력 폴더**로 찾을 수 있습니다. 백업에 실패하면 정리하지 않습니다. 외부 파일은 유지하고, 다시 직접 켤 때까지 외부 파일 자동 갱신을 끕니다. 복원하려면 앱을 닫고 현재 `usage-board.json`을 따로 보관한 뒤 원하는 백업을 이 파일에 복사합니다.

셔터 작동 횟수 옆 **!**에 마우스를 올리거나 클릭하면 종료 시 셔터 동작 설명을 볼 수 있습니다. 다시 클릭하거나 Escape로 닫습니다. 공식 설정명은 [전원 차단 시 셔터 동작](https://eww.pavc.panasonic.co.jp/dscoi/DC-S1RM2/html/DC-S1RM2_DVQP3260_kor/0130.html)입니다. +1은 이 프로젝트의 DC-S1RM2 / 펌웨어 1.5 시험에서 관찰한 내용이며, 모든 카메라에 대한 공식 카운터 보증은 아닙니다.

### 기록 선택과 삭제

**사용 이력**의 각 행을 체크한 뒤 **선택 삭제 (n)**를 누릅니다. 페이지를 넘겨도 선택은 유지되고, 카메라 필터를 바꾸면 해제됩니다. **선택 해제**는 체크한 항목을 모두 해제합니다. 삭제 건수를 확인한 뒤 진행하세요. `history-backups`에 전체 백업을 먼저 만들며 백업에 실패하면 삭제하지 않습니다. 외부 이력 사본은 유지하고 자동 덮어쓰기를 끕니다.

삭제한 구간은 표시를 남겨 잘못된 증가량으로 이어 계산하지 않습니다. 처음 선택 삭제를 한 뒤부터 이 이력은 **v1.1.0 이상**에서 관리하세요. 이전 빌드는 갱신된 형식을 읽을 수 없습니다. 삭제 직전 백업은 원래 형식을 유지하므로 필요하면 위 복원 방법을 이용하세요.

### 일별·월별·연별 분석

**사용 이력 → 분석**에서 카메라 한 대를 선택하고 **일별 / 월별 / 연별**, **셔터 / 전원·깨우기**를 고릅니다. 한 화면에 8개 기간을 표시하며 이전·다음으로 이동합니다. 카메라를 연결하지 않아도 분석을 볼 수 있습니다.

막대는 같은 기간 안에서 비교 가능한 조회 사이의 관측 증가량이며, 그 기간의 실제 촬영 매수 전체를 뜻하지 않습니다. **0**은 비교 결과 증가가 없다는 뜻이고 **—**는 비교 가능한 구간이 없다는 뜻입니다. 기록을 꾸준히 남기면 비교 자료가 쌓입니다. 기간 경계는 PC의 현지 날짜를 기준으로 합니다.

서로 다른 기간의 조회 사이에서 발생한 증가는 막대에 임의로 배분하지 않고, 선택한 바디의 전체 이력을 기준으로 그래프 아래에 따로 표시합니다. 더 넓은 월별·연별 기간에서는 비교 가능해질 수 있습니다. 펌웨어 변경·카운터 초기화·검증 상태 변경·삭제 구간은 비교에서 제외합니다. 추정 기록에는 추정 표시를 유지합니다. 셔터와 전원 그래프의 눈금은 각각 조절됩니다.

### 연결 문제

앱 창이 열리기 전에 시작 오류가 표시되면 문의할 때 화면의 단계와 코드를 함께 알려 주세요. 이미 실행 중이라는 안내가 나오면 열려 있는 창을 이용하세요.

고정된 하단 **연결 및 진단** 탭을 엽니다. 여러 기기가 감지되면 카메라를 선택하세요. 실행 중인 조회도 이곳에서 중단할 수 있습니다.

**조회 원본**에서 연결과 조회의 단계별 결과를 확인합니다. **진단 ZIP 저장**은 최근 조회를 저장하므로 특정 실패 결과가 필요하면 재조회 전에 저장하세요. ZIP에는 전체 시리얼, 장치 경로, 카드 이름, 파일명, 전체 원본 응답이 포함되지 않습니다. 자동 업로드는 없습니다.

ZIP과 증상·기종·펌웨어를 [GitHub 이슈 게시판](https://github.com/BieupHieut/LUMIX-Usage-Info/issues)이나 인스타그램 **@bieup_hieut** DM으로 보내 주세요.

### 언어
