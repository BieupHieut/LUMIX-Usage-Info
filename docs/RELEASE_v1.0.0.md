# LUMERIAN-LUMIX Usage Info v1.0.0

2026-10-03 · Windows x64 · 한국어 / English

## 다운로드 / Download

**LUMIX_Usage_Info_v1.0.0_Windows_x64.zip**을 다운로드하고 압축을 푼 뒤 실행하세요. 실행 파일 옆에 camera_profiles.json을 함께 둡니다.

Download and extract the Windows x64 ZIP. Keep camera_profiles.json beside the executable.

## 기능 / Features

- 모델·펌웨어·시리얼, 셔터 작동·전원/깨우기 횟수 / Camera information and usage counters
- 오류 기록 및 원시 카운터 / Error history and raw counters
- PNG·TXT 저장, 요약 복사, 시리얼 공개 범위 / PNG/TXT export, clipboard summary and serial privacy
- Windows 언어 자동 선택 및 한/영 전환 / Automatic and manual Korean/English
- 검증 목록, 지원 추정 목록, USB 연결 안내 / Verification, estimated support list and USB guidance

## 연결 / Connection

카메라를 켜고 데이터 USB 케이블로 PC에 연결합니다. 일반 지원 기종은 PC(테더), DC-L10은 LUMIX Lab을 선택한 뒤 연결 / 새로고침을 누르세요. 다른 카메라 앱은 먼저 종료합니다.

Power on, connect a USB data cable to the PC, select PC(Tether) or LUMIX Lab for DC-L10, then Connect / Refresh. Close other camera applications first.
