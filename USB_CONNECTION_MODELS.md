The list follows [Panasonic's LUMIX Tether supported cameras](https://av.jpn.support.panasonic.com/support/global/cs/soft/download/d_lumixtether.html). Available modes/functions depend on camera firmware. Listing here does not guarantee this reader's protocol or count meanings on every pair. Close the LUMIX Tether application before using the reader.

## LUMIX Lab

DC-L10 / 1.2: community-confirmed using LUMIX Lab USB mode on the camera, connected to the PC. A smartphone or separate test app is not required for this reported reader workflow. Do not assume every Lab-compatible model is supported by this path.
